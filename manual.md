# Инструкция по работе с таблицей «Автоматизация прайса Миа-Аморе»

> Версия: 1.0 | Обновлено: 09.04.2026

## Что делает система

Сравнивает прайс поставщика Platina с товарами в магазине InSales, обновляет цены и остатки.

**Технология:** Google Sheets + Google Apps Script (`appsscript/Код.gs`)
**Домен магазина:** elenason.myinsales.ru

---

## Шаг 1. Обновить прайс поставщика

**Когда:** поставщик обновил остатки/цены на miamia.ru

**Вариант А — автоматически (если сайт доступен):**
1. Расширения → Apps Script
2. Выбрать функцию `обновитьПрайсПоставщика`
3. Нажать Выполнить
4. Дождаться алерта — функция сама обновит лист Поставщик и запустит обновитьСводную

**Вариант Б — вручную через файл:**
1. Скачать `ostatki-Platina.xlsx` с сайта поставщика
2. Загрузить файл на Google Drive (заменить старый)
3. Запустить `шаг1_Конвертировать` → дождаться алерта
4. Запустить `шаг2_Импорт` → дождаться алерта «Загружено строк: N»
5. Запустить `обновитьСводную`

---

## Шаг 2. Обновить прайс магазина

**Когда:** изменились товары/цены в InSales (добавили новые, изменили артикулы)

1. В Apps Script выбрать функцию `загрузитьМойПрайс`
2. Нажать Выполнить
3. Прогресс виден в ячейке D1 листа «Настройки» — «Загрузка: стр. N...»
4. Дождаться алерта «Загружено N вариантов» — в лист «Мой прайс» попадут только артикулы `ми*`

> Файлы вручную скачивать и загружать не нужно — данные берутся напрямую из InSales через API.

---

## Шаг 3. Обновить Сводную

**Когда:** после обновления любого из прайсов

1. Запустить `обновитьСводную`
2. Дождаться алерта с итогами:
   - **Совпало** — товары найдены у поставщика (зелёные строки в Сводной)
   - **Нет у поставщика** — остаток обнулён (красные строки)
   - **Новые товары поставщика** — есть у поставщика, нет в магазине (лист «Новые товары»)

---

## Шаг 4. Выгрузить в InSales

**Вариант А — через CSV-импорт (рекомендуется):**
1. Запустить `создатьФайлДляИмпорта` → файл появится на Google Drive
2. Скачать файл с Drive
3. В InSales: Каталог → Импорт → **Цены и остатки** → загрузить CSV
4. Дождаться завершения импорта, проверить лог ошибок

**Вариант Б — через API (только Совпавшие):**
1. Запустить `тестВыгрузки5строк` — проверить что код 200 OK
2. Запустить `полнаяВыгрузка` — прогресс в ячейке D1 листа «Настройки»

## Листы таблицы

| Лист | Содержимое |
|---|---|
| Поставщик | Данные из прайса Platina (артикул, название, размер, штрихкод, цена, остаток) |
| Мой прайс | Данные из InSales (ID варианта, артикул, цена, остаток) |
| Сводная | Результат сравнения. Зелёный = совпал, красный = нет у поставщика |
| Новые товары | Товары поставщика которых нет в магазине |
| История цен | Архив изменений |
| Настройки | Параметры системы |

---

## Логика совпадения товаров

Матчинг идёт в порядке приоритета:
1. **Полный артикул** — «ми3449 l/xl изумрудный» совпадает с поставщиком по артикул + размер/цвет
2. **Штрихкод** — если есть в Мой прайс
3. **Базовый артикул** — первое слово (ми3449), берётся первый вариант поставщика

---

## Важные правила

- Файл `ostatki-Platina.xlsx` не редактировать вручную
- В Сводную и Мой прайс попадают только артикулы `ми*` — остальные игнорируются
- Цена поставщика берётся из колонки Q прайса Platina («6 ПЛАТИНОВЫЙ»)
- Товары с нулевой ценой в InSales не выгружаются
- Перед полной выгрузкой через API всегда делать тест на 5 строках

## Установка Apps Script

1. Открыть Google Таблицу проекта
2. Расширения → Apps Script
3. Скопировать содержимое `appsscript/Код.gs` в редактор
4. Сохранить (Ctrl+S)
5. При первом запуске — выдать необходимые разрешения (Drive API, UrlFetch, SpreadsheetApp)

> **Примечание:** для работы функций конвертации xlsx требуется включить Drive API:
> Сервисы → Google Drive API → Добавить
